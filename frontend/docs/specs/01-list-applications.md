# 01 - List Applications

## Goal

Fetch job applications from Spring Boot and display them in a table.

## Requirements

- GET `/applications` from `localhost:8080`
- Fetch data when the page loads
- Display company, job title, location, status and date
- Render rows using `.map()`

## Technical

- React + TypeScript
- Native fetch
- Vite proxy for backend connection
- Minimal, readable code
- Simple CSS, no extra libraries

## Testing

- Check with real database data
- Run lint and build
